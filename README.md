# Manuk Martirosyan — Portfolio

Personal portfolio of a **Senior Frontend Developer** focused on enterprise React applications, scalable architecture, and workflow-driven interfaces.

**Live site:** [manukmartirosyan.com](https://manukmartirosyan.com)

## What’s inside

- Case studies for enterprise products (Field Service, CRM / sales workflows)
- Engineering highlights and skills
- Experience timeline
- Downloadable CV

## Stack

- **Next.js** (App Router)
- **React** + **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- Deployed on **Vercel**

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```
